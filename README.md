# Farah Aina — Library & Knowledge Management Portfolio

A static portfolio with project galleries, category filters and full-size image viewing.

## Open offline
Download the repository as a ZIP, extract it, and open `index.html` in a browser. Keep the assets folder and the JavaScript and CSS files beside it. No subscription or build step is needed.

## Enable GitHub Pages
In this repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then **Save**.

## Edit the portfolio
- Edit project wording and image lists in `portfolio-data.js`.
- Edit the home page, experience and contact details in `index.html`.
- Change colours and layout in `styles.css`.
- Put new compressed images in `assets/`. Gallery entries refer to the image filename without `.webp`.
- Keep meaningful captions and alt text. Check student privacy before adding photos.
